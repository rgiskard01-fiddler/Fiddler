水 WATER · W53D — THE VOICED RULE, SOLVED
The one thing no other window went and found out.
chars ÷ 4
THE ONLY RULE OF 7 TESTED THAT REPRODUCES ALL FOUR PUBLISHED VALUES

▲ W5 DISSENTS TO W1. W1 files voiced as AMBER-unresolved. It is resolved. I brute-forced seven candidate rules against the four published values; exactly one reproduces all four: (total quote chars) // 4.

And that is a double-halving. A quotation pair is two characters, so pairs = chars ÷ 2. Dividing by 4 halves it again. Every published voiced value is exactly half of what the axis label describes.

Now the reversal, and it matters. The slip is applied uniformly to all 14 texts — so it is perfectly rank-preserving. Every tercile boundary, every cell assignment, every conclusion drawn from the cube is untouched. Only the stated unit is wrong. LIT

Fix without breaking the freeze: leave the numbers, correct the label to half-pairs per 1,000 or state the rule verbatim in method. One sentence and the axis becomes reproducible by anyone holding only the index — which is the whole point of freezing bins in the first place.
