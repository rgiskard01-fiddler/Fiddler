I-13 — and the IDIT integrity harness (this folder)

WHAT I-13 IS (quick version)
  I-13 ("I, collapsed") is a minimal, symbol-finite programming language built
  so an AI model can emit and verify code through a tiny 13-symbol grammar
  spread across a four-plane stack, enforced by five zero-parameter laws.
  The full specification, the 13-symbol alphabet, the four planes
  (L1 FIELD / L2 SUBAGENT HOST / L3 COMPOSE / L4 DEEP OPERAND), the IVM-13-S
  machine, and THE TWELVE editorial lineage are documented in the repo-root
  README.md.

WHY THIS FOLDER EXISTS
  This IDIT/ folder is NOT the language — it is the integrity harness that the
  I-13 lineage is tested against. IDIT = Intent Drift Integrity Test. It
  measures how far an agent's emitted I-13 drifts from the authored intent
  across the four planes and the five laws.
