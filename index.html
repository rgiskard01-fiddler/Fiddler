I-13

I, collapsed. A symbol-finite coding language an AI can emit and verify — 13 symbols, four planes, five zero-parameter laws.

What I-13 is

I-13 is a minimal programming language built around one idea: collapse ordinary programming intent into a 13-symbol grammar that an AI can both produce and check without a sprawling vocabulary. It is a surface an agent emits and a verifier checks — not a language you hand-write for fun.

Four planes

  • L1 · FIELD — 395,162 nodes, 19-bit addresses, trained, 30-alpha.
  • L2 · SUBAGENT HOST — 209,068 nodes, 18-bit, trained, 66.
  • L3 · COMPOSE — 38,742 nodes, 16-bit, rewrite (0-param).
  • L4 · DEEP OPERAND — 6,662 nodes, 13-bit, cortex-only, 18.

Five zero-parameter laws

  1. veto — reject ill-formed collapse.
  2. -I — the I-symbol is subtractive / self-cancelling by construction.
  3. depth — bound the recursion / stack depth.
  4. idempotence — repeated application is stable.
  5. address — address resolution is closed (0 params).
